# سیستم نوبت‌دهی آنلاین (Nobatgiri)

سیستم کامل رزرو نوبت با **PHP و MySQL** — بدون نیاز به فریم‌ورک و وابستگی خارجی.
راست‌چین، فارسی، واکنش‌گرا (موبایل‌اول) و مجهز به تقویم جلالی.

## امکانات

**فرانت‌اند (مشتری)**
- انتخاب شعبه، خدمت دسته‌بندی‌شده (قیمت، مدت، توضیح)
- انتخاب متخصص یا «بدون ترجیح»
- تقویم تعاملی جلالی با نمایش روزهای تعطیل/تکمیل
- ساعت‌های خالی دقیق بر اساس شیفت، استراحت و رزروها
- ورود با کد تأیید پیامکی (OTP) برای جلوگیری از رزرو فیک
- پرداخت آنلاین کامل یا بیعانه
- پیگیری نوبت، لغو با سیاست استرداد، صف انتظار
- افزودن به Google Calendar + دانلود ICS

**پنل مدیریت**
- داشبورد با نمودار درآمد و آمار روزانه
- مدیریت رزروها (فیلتر، تغییر وضعیت، جابه‌جایی، یادداشت)
- مدیریت خدمات، متخصصان، شعبه‌ها
- شیفت‌های هفتگی (پیش‌فرض شعبه + اختصاصی)، استراحت‌ها، تعطیلات
- پرونده مشتریان (سابقه، یادداشت)
- صف انتظار با پیشنهاد خودکار پیامکی
- صف اعلان‌ها + اجرای دستی + لاگ پیامک
- گزارش مالی/آماری (خدمت، متخصص، روزانه) + خروجی CSV
- تنظیمات: قوانین رزرو، لغو، یادآوری، پیامک، درگاه

**هوشمند**
- یادآوری خودکار: ثبت، ۲۴ ساعت قبل، ۲ ساعت قبل (کرون‌جاب)
- سیاست لغو: رایگان تا X ساعت قبل، جریمه درصدی پس از آن
- محافظت از رزرو هم‌زمان: تراکنش + قفل سطح دیتابیس + ایندکس یکتا

## پیش‌نیازها

- PHP 8.0 یا بالاتر با افزونه‌های: `pdo_mysql` (یا `pdo_sqlite`)، `mbstring`، `json`
- MySQL 5.7+ / MariaDB 10.3+ (برای محصول نهایی)
- برای تست سریع بدون MySQL، حالت SQLite داخلی کافی است.

## نصب

### روش ۱: نصب‌کننده تحت وب (پیشنهادی)
1. فایل‌ها را روی هاست/لوکال‌هاست بریزید (مثلاً `public_html/`).
2. مطمئن شوید پوشه‌ی `storage/` قابل نوشتن است.
3. در مرورگر باز کنید: `https://domain.com/install.php`
4. نوع دیتابیس، مشخصات MySQL و مدیر را وارد و نصب کنید.
5. **حتماً `install.php` را حذف کنید.**

مشخصات نمایشی مدیر: `09120000000` / `admin123`

### روش ۲: لوکال‌هاست
```bash
cd nobatgiri
php -S 127.0.0.1:8000
# سپس باز کنید: http://127.0.0.1:8000/install.php
```

## کرون‌جاب (ضروری برای یادآوری‌ها)

هر ۵ دقیقه یک‌بار اجرا شود:

```bash
# CLI
*/5 * * * * php /path/to/nobatgiri/cron.php

# یا HTTP (کلید در صفحه تنظیمات)
https://domain.com/cron.php?key=CRON_KEY
```

کارها: آزادسازی رزروهای پرداخت‌نشده، ارسال پیام‌های سررسیده، انقضای پیشنهادهای قدیمی صف انتظار.

## اتصال پیامک واقعی (کاوه‌نگار)

1. در پنل مدیریت ← تنظیمات، درایور را `کاوه‌نگار` کنید و کلید API را وارد کنید.
2. در حالت `log` پیام‌ها در `storage/logs/sms.log` ذخیره و کد تأیید در صفحه نمایش داده می‌شود (فقط نمایشی).

## اتصال درگاه واقعی (زرین‌پال)

1. در تنظیمات، درگاه را `زرین‌پال` و مرچنت‌کد را وارد کنید.
2. روی سرور باید `curl` فعال باشد.
3. در حالت `simulated` پرداخت نمایشی است و مبلغی کسر نمی‌شود.

## مدیریت تداخل زمانی (Concurrency)

- کلید یکتای `slot_key` فقط برای نوبت‌های فعال (با لغو/اتمام آزاد می‌شود تا ساعت قابل رزرو مجدد باشد)
- بررسی تداخل بازه‌ای داخل تراکنش با `SELECT ... FOR UPDATE`
- رزروهای پرداخت‌نشده پس از X دقیقه (پیش‌فرض ۲۰) خودکار آزاد می‌شوند.

## ساختار پروژه

```
├── index.php          # فرانت‌اند (ویزارد رزرو + پیگیری)
├── api.php            # API فرانت‌اند و پنل (JSON)
├── pay.php / verify.php / ics.php
├── cron.php           # یادآوری‌ها و آزادسازی
├── install.php        # نصب‌کننده
├── config.php         # پیکربندی + اتصال PDO
├── lib/               # Jalali, Booking, Notify, Payment, Auth, ...
├── database/          # schema_mysql.sql / schema_sqlite.sql / seed.php
├── admin/             # پنل مدیریت
├── assets/            # css/js (بدون وابستگی خارجی)
└── storage/           # sqlite، لاگ‌ها (قابل نوشتن باشد)
```

## امنیت محصول نهایی

- حذف `install.php`، غیرفعال بودن `APP_DEBUG`
- محدود کردن دسترسی مستقیم به `storage/` (مثلاً با `.htaccess`)
- HTTPS برای پرداخت و ورود
